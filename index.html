Тема try / except — большая ловушка для ошибок

Это самая важная тема для всех «викторин» в задачах. Разбираем максимально подробно.

Зачем это вообще нужно?

Функция input() возвращает строку. Даже если ты введёшь 3, это будет строка '3', а не число.

Чтобы сравнить ответ с числом, строку превращают в число через int(). Но если пользователь введёт «три» или «3,5», int() падает с ошибкой — программа ломается. Вот тут и спасает try/except.

🔍 Мини-пример: как это работает

1

Проблема: без защиты.

a = int(input('Сторона квадрата:')) print('Периметр:', a * 4)

Если пользователь введёт 5 — всё ок. Если пять — программа «упадёт» с красной ошибкой. Это плохо.

2

Решение: оборачиваем опасный код в try.

while True: try: a = int(input('Сторона квадрата:')) break except: print('Ошибка! Введите число без других символов') perimeter = a * 4 print('Периметр квадрата:', perimeter)
3

Что происходит по шагам:

СтрокаДействие
while True:Бесконечный цикл. Пока не выйдем через break.
try:Начало «безопасной зоны». Всё внутри мы пытаемся выполнить.
a = int(input(...))Пытаемся прочитать строку и превратить её в целое число.
breakЕсли получилось — выходим из цикла. Число надёжно сохранено в a.
except:Если int() не смог — управление прыгает сюда. Печатаем подсказку. Цикл идёт на новый круг.
💡 Главная мысль: try — «попробуй», except — «а если не вышло, сделай вот это». break живёт внутри try, чтобы выйти из цикла только когда ошибок не было.

🧩 Как это встроено в викторины

1

В задачах-викторинах структура почти всегда одинаковая:

while True: try: answer = int(input()) break except: print('Ошибка! Введите номер правильного ответа')

Читается так: «Пока не получим нормальный номер — проси ввести заново».

2

Почему while True именно бесконечный? Потому что мы не знаем заранее, сколько раз пользователь ошибётся. break — единственный выход. Это стандартный «паттерн» для ввода с проверкой.

3

Что попадёт в except? Например:

  • пользователь ввёл буквы — 'abc';
  • ввёл дробное — '3.5' (у int() не пройдёт);
  • просто нажал Enter — пустая строка.
Проверь себя

Вопрос:

Почему break стоит именно после int(...), а не до него?

Показать ответ

Потому что если поставить break до int(...), цикл закончится сразу после ввода строки, ещё до попытки превратить её в число. Тогда ошибка не будет поймана, и except никогда не сработает. А если break вообще убрать из try — цикл будет бесконечным даже при верном ответе.

Итог

Шаблон для запоминания:

while True: try: x = int(input('Введите число: ')) break except: print('Ошибка! Введите число без других символов')

Дальше можно спокойно пользоваться x как числом.

1.2 Подбор кошки

Вложенные if/else + ввод числа.

Что делает программа

  1. Спрашивает про аллергию.
  2. Если «да» — сразу советует Канадского сфинкса.
  3. Если «нет» — спрашивает про пушистость.
  4. Если не хочет пушистую — Шотландская вислоухая.
  5. Если хочет — спрашивает цену и по цене советует породу.

🔍 Разбор по шагам

1

Первый вопрос и первая развилка.

allergy = input('У вас есть аллергия? (да/нет)') if allergy == 'да': print('Вам подходит Канадский сфинкс')

Сравниваем строку с 'да'. Важно: input() возвращает строку, кавычки нужны.

2

Ветка «нет» — вложенный вопрос.

else: wool = input('Хотите пушистую кошку? (да/нет)') if wool == 'нет': print('Может, Шотландская вислоухая?')

Второй if находится внутри else — это вложенность.

3

Цена и последняя развилка.

else: price = int(input('Введите комфортную цену:')) if price < 10000: print('Оцените Персидского экзота!') else: print('Взгляните на Мейн-кунов!')

int() превращает строку в число, чтобы сравнить с 10000.

💡 Подсказка: обрати внимание на отступы. Каждый if/else «привязан» к своему уровню. Если сбить отступы — логика сломается.
Улучшение

Что будет, если пользователь введёт цену буквами? Программа упадёт. Как это починить? — Обернуть ввод цены в try/except (см. страницу «try/except»).

1.3 Билеты в кино

Линейная программа: ввод → подсчёт → вывод.

Что делает программа

Спрашивает, сколько взрослых, детей и пожилых. Считает общую стоимость по фиксированным ценам.

🔍 Разбор по шагам

1

Вывод цен (для справки).

print('Цена взрослого билета (18-65) - 1500') print('Цена детского билета (до 18) - 1100') print('Цена билета старшего поколения (после 65) - 900')
2

Ввод количества.

adult_amount = int(input('Всего взрослых')) children_amount = int(input('Всего детей')) retired_amount = int(input('Всего пожилых'))

Каждое значение сразу превращается в число.

3

Формула и вывод.

total = adult_amount*1500 + children_amount*1100 + retired_amount*900 print('К оплате:', total)

Сначала умножение, потом сложение — как в математике.

Проверь себя

2 взрослых, 1 ребёнок, 1 пожилой. Сколько получится? Посчитай в голове, потом проверь кодом.

Ответ

2·1500 + 1·1100 + 1·900 = 3000 + 1100 + 900 = 5000.

1.4 Наименьшее из трёх

Три независимых if — обрати внимание, что это не elif.

🔍 Разбор по шагам

1

Ввод трёх чисел.

a = int(input('Первое число')) b = int(input('Второе число')) c = int(input('Третье число'))
2

Проверяем каждое число отдельно.

if a <= b and a <= c: print('Первое - наименьшее') if b <= c and b <= a: print('Второе - наименьшее') if c <= a and c <= b: print('Третье - наименьшее')

Каждое if проверяет: «это число меньше или равно двум другим?»

💡 Зачем <=, а не <? Чтобы при равных числах (например, 5, 5, 7) сработало сразу два if — программа честно скажет, что наименьших несколько.
Проверь себя

Числа 7, 7, 7 — сколько строк выведет программа?

Ответ

Три строки: все три числа являются наименьшими.

1.5 Тип треугольника

Каскад if / elif / else.

🔍 Разбор по шагам

1

Ввод трёх сторон.

a = int(input('Первая сторона:')) b = int(input('Вторая сторона:')) c = int(input('Третья сторона:'))
2

Проверка равносторонности.

if a == b and a == c: print('Треугольник равносторонний')

Если все три равны — дальше проверять нечего. elif уже не выполнится.

3

Проверка равнобедренности.

elif (a == b and a != c) or (b == c and a != c) or (a == c and a != b): print('Треугольник равнобедренный')

Три пары в скобках — это «ИЛИ»: хотя бы одна пара сторон должна совпадать. Условие a != c и т.п. нужно, чтобы исключить уже отловленный равносторонний случай.

4

Всё остальное.

else: print('Все стороны имеют разные длины')
💡 Как читать длинное условие: разбей его на три блока по or. Первый — a=b, второй — b=c, третий — a=c. Каждый блок — отдельный «шанс» на равнобедренность.

1.6 Сумма от 1 до N

Классический цикл while с накоплением.

🔍 Разбор по шагам

1

Подготовка.

number = int(input('Введите число:')) i = 1 total = 0
  • i — счётчик, начинается с 1.
  • total — копилка, начинается с 0.
2

Цикл.

while i <= number: total += i i += 1

Пока счётчик не превысил number: добавляем его в копилку и увеличиваем на 1.

3

Вывод.

print('Сумма чисел от 1 до', number, 'равна', total)
💡 Трассировка для number = 4:
i=1: total=1 → i=2 → total=3 → i=3 → total=6 → i=4 → total=10 → i=5 → цикл стоп. Ответ 10.

1.7 Угадай число (без рандома)

Цикл while с подсказками «больше/меньше».

🔍 Разбор по шагам

1

Загаданное число — фиксированное.

my_number = 9 number = int(input('Я загадала число от 1 до 10. Угадай его:'))
2

Цикл, пока не угадали.

while my_number != number: if my_number < number: number = int(input('Нет, моё число меньше! Попробуй снова:')) else: number = int(input('Нет, моё число больше! Попробуй снова:'))

Условие цикла: пока не равно. Внутри — две подсказки и новый ввод.

3

Финал.

print('Ты угадал!')

Когда цикл завершился, значит number == my_number.

Проверь себя

Загадано 9. Игрок ввёл 5. Какую подсказку он получит и что произойдёт дальше?

Ответ

5 < 9, значит my_number < number ложь → сработает else → «моё число больше!». Игрок вводит новое число.

1.8 Угадай число (с рандомом)

Отличие от 1.7 — одна строчка импорта и генерации.

🔍 Разбор по шагам

1

Импорт и генерация.

from random import randint my_number = randint(1, 10)

randint(1, 10) возвращает случайное целое от 1 до 10 включительно.

2

Дальше — точно как в 1.7.

number = int(input('Я загадала число от 1 до 10. Угадай его:')) while my_number != number: if my_number < number: number = int(input('Нет, моё число меньше! Попробуй снова:')) else: number = int(input('Нет, моё число больше! Попробуй снова:')) print('Ты угадал!')
💡 Важно: каждый запуск программы загадывает новое число. Чтобы проверить логику подсказок, можно временно вывести my_number на экран.

2.2 Факты о теле + время работы

Викторина с try/except и замером времени.

Что делает программа

  1. Запоминает время старта.
  2. Задаёт вопрос и выводит 4 факта.
  3. Просит ввести номер через try/except.
  4. Сравнивает с правильным ответом (4).
  5. Считает и печатает время работы.

🔍 Разбор по шагам

1

Импорт времени и старт.

from time import * start = time()

time() возвращает текущее время в секундах (дробное число).

2

Вывод вопроса и фактов.

print('Укажи номер ложного факта о человеческом теле') print('1-Смеяться и чувствовать щекотку одновременно невозможно') print('2-Человеческий волос живёт от 2 до 5 лет') print('3-Чтобы сделать 1 шаг, нужно задействовать 200 мышц') print('4-У далёкого предка человека 6 пальцев')
3

Ввод с защитой — снова шаблон из темы try/except.

while True: try: answer = int(input()) break except: print('Ошибка! Введите номер без других символов')

Работает точно так же, как разобрано на странице «try/except».

4

Проверка ответа.

if answer == 4: print('Именно так!') else: print('Нет, у человека никогда не было 6 пальцев')
5

Финиш времени и вывод.

end = time() print('Время работы программы', end - start)

Разница end - start — сколько секунд работала программа.

Проверь себя

Что будет, если ввести 4? А один?

Ответ

При 4 — «Именно так!». При один — сработает except, программа попросит ввести номер заново.

💡 Мелочь, но важно: from time import * импортирует всё из модуля. Лучше писать import time и потом time.time() — но в учебных задачах часто пишут как в примере.
